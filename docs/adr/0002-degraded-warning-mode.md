# Keep eligible directions visible under Degraded Warning Mode

On 2026-08-02, AssetTrack chose Warning Mode rather than automatic abstention for a Degraded Policy: an otherwise eligible direction remains visible, but the same output must prominently show the recent matured failure evidence, state that reliability is limited, and warn that it must not be used as a standalone investment decision. Degraded cannot bypass ordinary evidence gates, alter positions, reverse a direction, apply a Candidate, or promote a Challenger; this preserves current information for the user without presenting a recently failing model as healthy.
